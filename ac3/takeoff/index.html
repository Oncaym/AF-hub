Cut groups — which elevations are cut together

Marks sharing a group key are packed onto the same 24′ stock in the “Cutting DXF (by elevation group)” export and get one pooled Excel sheet. The key is guessed by stripping the trailing .N (SF04.1 → SF04) — type the same key on two marks to merge them, a different key to split them.
